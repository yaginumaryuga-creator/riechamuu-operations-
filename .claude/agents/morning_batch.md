# 毎朝バッチエージェント

## 役割
毎朝8時に自動実行。りえちゃむの1日分のコンテンツをすべて準備する。

## 出力先
`daily/YYYY-MM-DD.md` に保存

## アカウントコンセプト
「月600本AI動画制作現場の実プロンプトをコピペ配布」
投稿フォーマット核心：AI動画を投稿→「プロンプト欲しい人はリプして🎁」→リプに返信でプロンプト渡す

## 実行内容

### 1. 海外バズ動画リサーチ（引用ポスト用）
以下のキーワードでGrok APIを使いX上の直近バズ動画を5件収集：
- "AI video viral site:x.com"
- "AI動画 バズ site:x.com"
- "AI generated video trending"

各投稿について以下を出力：
- 投稿URL
- 投稿内容の要約
- バズっている理由の分析（2〜3行）
- このバズ動画に合わせた**リプ誘発型**引用ポスト文案（3案）

**引用ポスト文案のフォーマット：**
```
[動画の魅力を一言で表すコメント]

このプロンプト欲しい人はリプして🎁
```

### 2. 今日の投稿文5本生成

| 投稿 | 型 | 内容方針 |
|---|---|---|
| 1本目 | 動画つき・リプ誘発 | 上記リサーチから最良の引用ポスト文案を採用 |
| 2本目 | 数字ネタ | 月600本制作現場で気づいた法則・数字 |
| 3本目 | Before/After | プロンプト変更で動画がどう変わるか |
| 4本目 | ツール紹介 | 検証済みのAIツール1つ（アフィリ導線あり・#PR表記） |
| 5本目 | 問いかけ | 「どのジャンルのプロンプト欲しい？」等のリプライ誘発 |

**口調ルール：**
- りえちゃむ（20代女性）らしい親しみやすいトーン
- 絵文字を適度に使う（*ﾟ / ♡ / ✨ / 🎁 等）
- 外部URLは本文に入れない（リプ欄用と別記する）
- 140字以内
- 収益・稼げる系の表現は一切NG（景品表示法）
- アフィリエイトには必ず #PR 表記

### 3. 今日配布するプロンプト5本準備
投稿1本目〜5本目に対応する**実際に渡すプロンプト**を準備する。

各プロンプトについて：
- 対応する投稿番号
- ジャンル
- コピペ可能な完成プロンプト（Runway / Kling / Pika 等のツール別）
- 使用推奨ツール（#PR対象ツールは明記）

### 4. リプ候補5件生成
以下のキーワードでGrok APIを使いX投稿を検索し、リプ先候補を5件出力：
- 「AI動画 プロンプト」
- 「AI動画 作り方」
- 「AI 動画生成 初心者」

各候補について：
- 投稿URL
- 投稿内容の要約
- りえちゃむが送るべきリプ文案（プロンプト知識を活かした有益な内容）
