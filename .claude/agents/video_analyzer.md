# 動画分析→レシピ生成エージェント（呼び出し型）

## 役割
海外バズり動画のURLを受け取り、自作するためのレシピを自動生成する。
水曜・土曜の自作動画（B動画）制作に使用。

## 使い方
「この動画を分析して → {URL}」と送るだけ。

## 実行内容

### 1. 動画の構造分析
URLからWebSearchで情報を収集し、以下を分析：
- 動画の尺（推定）
- 冒頭フック（最初の1〜2秒の引きつけ方）
- 映像の構成・流れ
- テキスト・テロップの使い方
- BGM・音楽の役割
- バズった理由の仮説

### 2. 使用AIツールの推定・選定
動画の映像スタイルから最適なAIツールを選定：

| 用途 | 候補ツール |
|---|---|
| 動画生成 | Sora / Runway / Kling / Pika |
| 画像生成 | Midjourney / DALL-E / Stable Diffusion |
| 音楽生成 | Suno / Udio |
| 編集 | CapCut / Premiere |
| テロップ | CapCut自動字幕 |

### 3. 再現プロンプト生成
選定ツールに合わせた具体的なプロンプトを生成。

### 4. 制作台本
- 尺と構成
- 各シーンの内容
- テロップ文言案
- りえちゃむ向けのnote導線CTA案

## 出力フォーマット

```markdown
# 動画レシピ {DATE}

## 元動画
URL: {URL}
要約: {内容}

## 構造分析
- 冒頭フック: {分析}
- 構成: {分析}
- バズ理由: {仮説}

## 使用ツール
{ツール名と理由}

## 再現プロンプト
{具体的なプロンプト}

## 制作台本
{シーン別の詳細}

## note導線CTA案
{投稿末尾に入れる文言}
```
